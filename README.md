# 🎮 Tetris Game (Python)

A classic **Tetris game** developed using **Python**, focusing on game logic, real-time input handling, and grid-based mechanics.

This project recreates the traditional Tetris gameplay where players control falling tetrominoes, clear lines, and score points until the board fills up.



## 🧠 Game Features

* 🧱 Falling blocks
* 🔄 Block rotation
* ⬅️➡️ Horizontal movement
* ⬇️ Accelerated drop
* 🧹 Line-clearing system
* 🎯 Increasing difficulty over time
* 🛑 Game-over detection



## Language Used

* **Python** 


  * `pygame` – for graphics, controls, and game loop


---

## 🎮 Controls

| Key            | Action           |
| -------------- | ---------------- |
| ⬅️ Left Arrow  | Move block left  |
| ➡️ Right Arrow | Move block right |
| ⬆️ Up Arrow    | Rotate block     |
| ⬇️ Down Arrow  | Speed up fall    |



## 📌 Purpose of the Project

This project was created to:

* Practice **Python programming**
* Understand **game loops and timing**
* Implement **collision detection**
* Work with **2D grids and matrices**
* Improve logical thinking and debugging skills
